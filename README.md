# Karyawan Tiri

Web app dashboard untuk memantau penyaluran pupuk, laporan, dokumen, PUD, dan PPTS.

## Menjalankan aplikasi

```bash
npm install
npm run dev
```

> Data yang ada saat ini masih berupa mock data. Integrasi Google Sheets/Drive akan ditambahkan setelah endpoint publik/API dan struktur file sumber dikonfirmasi.
